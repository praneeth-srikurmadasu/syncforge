# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through
GitHub's **Report a vulnerability** button on the repository's **Security** tab (private
vulnerability reporting). Include the steps to reproduce and the affected version or
commit.

You can expect an acknowledgement within a week.

## Scope

SyncForge is a portfolio project. Its connectors run against local simulated services,
and the provided Docker Compose setup is for local use. The security design, and what is
deliberately not implemented, is described in [docs/security.md](docs/security.md).
